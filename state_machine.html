State machine: พ.1 → พจ.1 (ตามไอเดียที่เสนอ)

สถานะปัจจุบัน เริ่มต้น

สถานะปัจจุบัน ผ่าน/จบดี ยกเลิก/ปฏิเสธ ล็อก (ทำอะไรใน พ.1 ไม่ได้)

ปุ่มที่กดได้ตอนนี้ (แยกตามผู้ใช้)

กฎที่ใช้

  1. หนังสือโดนตีกลับ → หนังสือ returned และ พ.1 กลับแบบร่างทันที
  2. เจ้าของใบดึงกลับได้ทุกขั้น · ผู้ตรวจสอบ/ผู้ยืนยันงบตีกลับได้ · ต้องใส่เหตุผลทั้งคู่
  3. โดนตีกลับ/กลับแบบร่าง → ใบจองเงินยกเลิก แล้วค่อยจองใหม่
  4. ยกเลิก พ.1 ได้เฉพาะแบบร่าง และเฉพาะ user_id (ปุ่มแดง)
  5. รอพิจารณาให้จัดหา (sent) ทำอะไรใน พ.1 ไม่ได้
  6. ปุ่มกลับแบบร่างแสดงตลอด กดไม่ได้เมื่อหนังสือไม่ใช่ draft/returned
  7. ส่งหนังสือใหม่ได้เมื่อ พ.1 = to_approve
  8. หนังสือโดนปฏิเสธ → ยกเลิกทั้งหมด (พ.1, ใบจองเงิน, หนังสือ)
  9. พ.1 ยกเลิกแล้วห้ามกลับแบบร่าง และหนังสือถูกยกเลิกด้วย
  10. ผู้สร้าง พจ.1 อัตโนมัติ = ผู้ใช้ที่ตั้งค่าไว้ (ไม่ตั้ง = OdooBot)
  11. e-GP ถูกยกเลิก → กดกลับแบบร่างได้
  12. พจ.1 แบบร่าง มีแค่ สร้างหนังสือ / ยกเลิก
  13. ยกเลิก พจ.1 = ยกเลิกทั้งหมด (พ.1, พจ.1, หนังสือ, ใบจองเงิน) · ได้เฉพาะแบบร่าง
  14. หนังสือ พจ.1 โดนตีกลับ → พจ.1 แบบร่าง หนังสือ returned
  15. หนังสือ พจ.1 โดนปฏิเสธ → ยกเลิกทั้งหมด
  16. พจ.1 อนุมัติแล้วอยากยกเลิก → กลับแบบร่างก่อน แล้วกดยกเลิก
